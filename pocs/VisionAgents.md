# POC: 即時視覺 AI Agent 框架

## 概述
專業級的即時視覺 AI Agent 開發框架，讓您能夠建立會「看」、會「聽」、會「理解」影片的智慧 AI 助理。整合多種 AI 模型（YOLO、Gemini、OpenAI 等），提供低延遲的即時互動體驗，適合打造各種視覺 AI 應用。

## 使用方法

### 基本 Agent 建立
1. 安裝 Vision Agents 框架（使用 uv 或 pip）
2. 設定 Stream API 金鑰和模型 API 金鑰
3. 撰寫 Agent 程式碼，定義功能和行為
4. 執行 Agent
5. 透過網頁或行動裝置連接並互動

### 常見應用範例

**安全監控 AI**
- 人臉識別 + 物件偵測
- 自動產生警報和報告
- 即時語音互動

**電話語音助理**
- 透過 Twilio 接聽電話
- 整合 RAG 提供專業知識
- 即時語音對話

**提示**：框架提供豐富的整合套件，可快速組合出所需功能

## 主要功能
- **即時視訊 AI**：結合 YOLO 等模型與 Gemini/OpenAI，即時處理影片
- **低延遲連接**：加入會話僅需 500ms，音訊/視訊延遲低於 30ms
- **語音互動**：內建語音識別（STT）和語音合成（TTS）
- **多模型整合**：支援 Gemini、OpenAI、AWS Bedrock、Qwen 等 20+ 種 AI 服務
- **RAG 知識庫**：使用 TurboPuffer 提供專業領域知識
- **工具呼叫**：可執行自訂函數，串接外部 API

## 應用場景
- **安全監控**：智慧監控系統，自動偵測異常並發送警報
- **客服助理**：視訊或電話客服，提供即時專業支援
- **無人機監控**：火災偵測、環境監測等
- **會議助理**：即時會議記錄、摘要和協助

## 成本效益
- **快速開發**：預先整合 20+ 種 AI 服務，無需從頭建立
- **低延遲**：使用 Stream 的邊緣網路，確保即時互動體驗
- **開放架構**：可搭配任何視訊網路使用，不綁定特定平台
- **原生 API**：直接使用 OpenAI、Gemini 等原生 API，隨時存取最新功能
- **多平台 SDK**：提供 React、Android、iOS、Flutter、React Native、Unity SDK
