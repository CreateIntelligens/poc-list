# POC: 印尼語即時翻譯機

## 概述
基於 OpenAI Realtime API 的即時語音翻譯服務，專注於印尼語到繁體中文的即時口譯。使用者透過語音輸入印尼語，系統會即時翻譯成繁體中文並回應，提供流暢的跨語言溝通體驗。

## 使用方法

### 開始使用
1. 開啟即時翻譯網頁介面
2. 點擊「連接」按鈕，建立與翻譯服務的連線
3. 允許瀏覽器存取麥克風權限
4. 開始用印尼語說話
5. 系統會即時將您的印尼語翻譯成繁體中文並顯示

### 操作介面
- **語音輸入**：直接對著麥克風說印尼語
- **即時回應**：系統會立即翻譯並以繁體中文回應
- **事件日誌**：可在 UI 中查看完整的翻譯事件和 JSON 格式的 API 互動記錄

**提示**：系統使用 Whisper AI 進行語音識別，會自動偵測印尼語語音並精確翻譯

## 主要功能
- **即時語音翻譯**：印尼語語音即時轉換為繁體中文，無需等待
- **精確翻譯**：使用 GPT-4o Realtime 模型，提供準確的翻譯結果
- **語音識別**：整合 Whisper-1 模型，專門優化印尼語語音識別
- **即時互動**：使用 WebRTC 技術，確保低延遲的即時對話體驗
- **事件記錄**：完整記錄所有翻譯事件，方便追蹤和除錯

## 應用場景
- **商務會議**：印尼語客戶或合作夥伴的即時翻譯服務
- **客服支援**：為印尼語使用者提供即時翻譯的客服溝通
- **教育訓練**：印尼籍員工或學員的即時語言輔助
- **跨國協作**：促進台灣與印尼團隊的即時溝通
- **現場活動**：印尼語演講或簡報的即時翻譯

## 備註
- 需要 OpenAI API 金鑰才能使用
- 使用 GPT-4o Realtime 模型（gpt-4o-realtime-preview）
- 語音識別使用 Whisper-1 模型，專門設定為印尼語（ISO-639-1: id）
- 翻譯規則嚴格限定為印尼語輸入、繁體中文輸出
- 使用者需允許瀏覽器麥克風權限
