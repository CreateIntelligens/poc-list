# POC: 簡訊發送服務

## 概述
整合 Every8d 簡訊服務的網頁操作介面，提供友善的簡訊發送功能與完整的歷史記錄管理，同時開放 REST API 讓其他系統也能輕鬆串接發送簡訊。

## 使用方法

### 網頁介面發送
1. 開啟簡訊服務網頁（預設為 port 7870）
2. 選擇「單一簡訊」或「批次簡訊」頁籤
3. 輸入手機號碼（單一或多個號碼）
4. 輸入簡訊內容（建議不超過 70 字元）
5. 點擊「發送」按鈕
6. 系統會顯示發送結果和批次 ID

### 查詢餘額
- 點擊「查詢餘額」頁籤
- 系統會即時顯示 Every8d 帳戶的剩餘點數

### 查看歷史記錄
- 切換到「歷史記錄」頁籤
- 查看最近 20 筆簡訊發送記錄（包含網頁和 API 發送的記錄）

**提示**：批次發送時，號碼可用換行、逗號或分號分隔，系統會自動解析

## 主要功能
- **單一簡訊發送**：發送簡訊到單一手機號碼，即時顯示結果
- **批次簡訊發送**：一次發送到多個號碼，支援多種分隔方式（換行、逗號、分號）
- **餘額查詢**：即時查詢 Every8d 帳戶餘額
- **歷史記錄管理**：自動儲存所有發送記錄，可查看最近 20 筆，最多保留 100 筆

## 應用場景
- **系統通知**：自動發送系統警示、狀態更新給管理人員
- **驗證碼發送**：用戶註冊或登入時發送驗證碼
- **行銷活動**：批次發送促銷訊息給客戶群
- **預約提醒**：自動發送預約提醒通知
- **多系統整合**：透過 API 讓不同系統都能發送簡訊

- **自動記錄**：完整保留發送歷史，方便追蹤和稽核

## 備註
- 需先申請 Every8d 帳號才能使用（可至官網申請測試帳號）
- 手機號碼支援台灣格式（09xxxxxxxx）和國際格式（886xxxxxxxxx）
- 簡訊超過 70 字元會分段計費
- 系統會自動驗證手機號碼格式
