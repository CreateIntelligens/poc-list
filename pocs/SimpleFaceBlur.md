# POC: 人臉遮蔽工具

## 概述
智慧型人臉隱私保護工具，自動識別照片中的人臉並提供三種遮蔽方式，適合需要快速處理圖片隱私保護、創意內容製作的場景。支援單張或批次處理，在保護個資的同時，也能創造趣味性的視覺效果。

## 使用方法

### 基本操作
1. 開啟人臉遮蔽工具網頁
2. 點擊「上傳圖片」選擇要處理的照片
3. 點擊「檢測人臉」進行臉部辨識（系統會自動標記所有人臉）
4. 選擇遮蔽模式：
   - **表情符號**：用可愛 Emoji 遮蔽人臉
   - **高斯模糊**：專業級模糊效果
   - **卡通化**：AI 將人臉轉換為卡通風格（需 Gemini API）
5. 點擊「執行遮蔽」進行處理
6. 點擊「儲存結果」下載處理後的圖片

### 選擇性遮蔽（進階功能）
- 使用 **筆工具** 點擊要遮蔽的人臉（顯示紅框）
- 使用 **橡皮擦** 點擊不要遮蔽的人臉（顯示綠框）
- 快速操作：點擊「全選」或「全不選」

### 批次處理
1. 點擊「批次遮蔽」
2. 選擇多張圖片（按住 Ctrl 或 Cmd 多選）
3. 系統會自動處理所有圖片，並將結果儲存在原圖片目錄

**提示**：批次處理會自動遮蔽所有檢測到的人臉；若需選擇性遮蔽，請使用單張圖片的互動式選擇功能

## 主要功能
- **智慧人臉檢測**：自動精準識別照片中的所有人臉
- **三種遮蔽模式**：Emoji 表情、高斯模糊、AI 卡通化，滿足不同需求
- **互動式選擇**：靈活控制要遮蔽的人臉，保留重要人物
- **批次處理**：一次處理整個資料夾的圖片，提高效率
- **即時預覽**：操作前可即時查看效果
- **本地部署**：圖片處理在本地進行，保護隱私安全

## 應用場景
- **社群媒體**：照片發布前的隱私保護，遮蔽不願曝光的人臉
- **文件簡報**：商業文件、教學簡報中的人臉去識別化
- **新聞媒體**：新聞照片的個資保護處理
- **企業內部**：員工照片、活動記錄的隱私保護
- **教育研究**：研究用途的照片處理，保護受試者隱私
- **創意內容**：使用 Emoji 或卡通化創造趣味性視覺效果
